Latest Release: v0.5.0

iam-shrink

Local-to-Least-Privilege AWS IAM Policy Generator. Intercept AWS operations during test suites and synthesize production-grade security policies in seconds.

Download Binary (0.5.0) GitHub Repository

🍺 Install via Homebrew

One-line installation on macOS and Linux:

brew install smford/tap/iam-shrink

🐳 Run in Docker

Zero-install execution wrapping local test commands:

docker run --rm -v $(pwd):/workspace \
  ghcr.io/smford/iam-shrink:latest \
  run --format=tf -- pytest tests/

🐹 Go Install

Build and install the latest binary with Go 1.23+:

go install github.com/smford/iam-shrink/cmd/iam-shrink@latest

⚡ Instant Local Usage

Simply prefix your test command with iam-shrink run:

# Generate Terraform HCL from Go tests
iam-shrink run --format=tf --strict-arns -- go test ./...

# Generate GCP IAM Custom Role YAML from Python tests
iam-shrink run --format=gcp -- pytest tests/

# Evaluate historical CloudTrail blast radius safety
iam-shrink impact /var/log/cloudtrail/ proposed_policy.json

# Launch the interactive Web UI
iam-shrink ui --port=8080
